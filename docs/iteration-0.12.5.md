# 知行 0.12.5 · 会话操作与 Office

知行继续使用随包的 DeepSeek Harness `0.2.2-rc.5`。主聊天和侧边聊天使用同一组中英文规划、目标和压缩命令。会话中的操作按钮直接调整当前会话的目标、规划或上下文，给用户保留正在编辑的正文和附件。SDK 启动时校验命令定义。只发查询或控制命令时，测试核对了零模型请求。

在绑定目录的项目中，可直接要求 Agent 转换文档或重算工作簿。`office_convert` 和 `office_recalculate` 调用官方 OfficeKit，按所选执行权限审批写入，将结果另存于项目。已有同名文件会编号，源文件保留。生成结果进入当前会话的「产出」，历史记录由 Harness 事件恢复。重算刷新缓存，业务公式仍由使用者核对。

Windows 上的手动交办可用 `office_render` 查看 Office 或 PDF 版面。文档与幻灯片选择页码，工作簿使用准确的工作表名及可选 A1 区域。主进程渲染、运行本机 OCR 并按当前规则生成像素副本。Harness 仅将已批准的副本放进模型工具结果，隐私网关独立校验 MIME、字节长度和 SHA-256。最多四张，与手动视觉附件共用同一会话名额。变更隐私规则或凭证后，历史视觉副本需要在新会话中重新准备。

Office 工具的计算和渲染使用官方 OfficeKit。知行的审批、项目另存、原生交付事件和视觉边界由知行适配。上游 Office 插件的技能激活与临时文件生命周期、Office 全格式及各平台矩阵仍待验。 [能力地图](harness-capability-map.md) · [Windows 验收](windows-acceptance-0.12.5.md)
