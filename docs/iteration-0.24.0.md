# 知行 0.24.0 · 给每条回复加上赞/踩（对标桌面版的消息反馈）

## 问题

桌面版每条完成的助手消息下面都能点赞或踩，还能选一个固定分类、写一段备注。查 `dsh-message-feedback/README.zh.md`：这些记录写进 Session 日志，**不进模型历史**，模型既看不到也不会被打断；分类表由 `dsh-command-feedback` 统一拥有，共七个固定 id；Web 组合把备注上限定在 8192 字节（UTF-8）。

知行此前完全没有这个能力：用户想反馈只能自己写邮件。

## 怎么改

- `src/message-feedback.js`：七个分类 id 与桌面版逐字一致（`task-result`、`instruction-following`、`product-interaction`、`service-stability`、`resource-cost`、`security-privacy-permission`、`other`），标签用 `dsh-command-feedback/README.zh.md` 里的中文释义；备注按 **UTF-8 字节**校验（`note-blank`／`note-too-large` 与桌面版同名同义，8192 字节边界）；同一条消息后写覆盖先写。
- 主进程：`feedback.bin`（`safeStorage.encryptString` 落盘），IPC `feedback:load`／`feedback:save`／`feedback:clear`；错误码翻成中文句子再交给界面，不把码丢给用户。
- 界面：助手消息的回复操作里加「赞这条回复」「踩这条回复」；点开是一个面板——说明「只记在本机，不会发给模型，也不会随工作空间导出」、七个分类胶囊、备注框（带 `N / 8192 字节` 计数，超限禁存）、取消／清除／保存。已记录的消息下方显示一行「本机反馈：赞 · 任务结果」。
- 故意不做的：不把反馈塞进工作空间（否则导出、分享会带出去），不做「反馈影响模型」——桌面版明确不唤醒模型。

## 结果

- 源码 7 条单测：分类表、只收赞/踩、分类白名单、备注字节边界（`'a'×8192` 通过、`+1` 拒绝、中文按三字节算）、落盘时间戳、覆盖与删除、摘要行。
- 实包 `npm run test:feedback`：点真实按钮 → 面板 7 个分类且文案与桌面版一致 → 选「任务结果」写备注 → 保存后显示「本机反馈：赞 · 任务结果」 → 刷新仍在 → 清除后消失；**反馈操作期间模型请求数不增加**；`feedback.bin` 的字节里既没有备注明文也没有分类 id 明文。

## 边界

- 只做**逐消息**反馈。桌面版另有 `/feedback` 会话级命令与弹窗（同一套分类表），知行没有实现，也未核对桌面版弹窗的逐像素样子。
- 反馈只存在本机自己的加密文件里，**不是**桌面版那种 Session 日志事件；两者语义等价（不进模型历史、可清除），但存储位置与格式不同，不能声称「与桌面版同一份数据」。
- 没有做「反馈后自动上报」。桌面版也不上报，这里保持一致。
- 安装生命周期仍是 0.19.0 的 53 步；`ENOTFOUND` 文案仍未端到端触发；安装器未签名。
