# 知行 0.14.10 · 归档文件不再覆盖上一份

## 问题

0.14.8／0.14.9 的归档默认文件名是 `子会话-1.md`、`子会话-全部.md`，而且写盘时直接覆盖。同一个子任务归档两次，第一份就被悄悄换掉了；用户也不知道哪个文件是哪次交办的。

## 怎么改

- 默认文件名改成 `子会话-<会话名>-<yyyyMMdd>[-序号].md`：会话名过滤 Windows 非法字符、截断到 60 字，日期来自本机时间（`electron/archive-name.mjs`）。
- 写盘改成独占创建（`flag: 'wx'`）：目标已存在就依次试 `-2`…`-20`，20 次仍冲突才报错「同名归档已存在，且无法再命名，请换一个文件名。」，绝不覆盖。
- 归档提示里显示的是最终落盘路径，用户能直接看到 `-2` 后缀。
- 纯函数 `archiveFileName`／`numberedName` 由 `tests/archive-name.test.mjs` 钉住：标题里的 `\ / : * ? " < > |`、超长标题、空标题、非法日期、序号退让。

## 结果

| 层 | 结果 |
| --- | --- |
| 源码 | `npm test` 399 个：398 通过、1 跳过、0 失败（新增 4 个命名用例） |
| 实包 | `npm run test:archive` 6 项全过，新增「同名归档已存在时自动加 -2，不覆盖上一份」：预占目标文件 → 真实点击归档 → 新文件以 `-2.md` 结尾、内容完整 |
| 回归 | 打包源码 351、组件 14、站点 4、原生文件 5、错误文案 4、聊天失败 2、更新缓存 3、临时目录 2、ZIP 4，全部通过 |

## 边界

- 序号只在本目录内退让；跨目录不查重（不同文件夹里可以有同名归档）。
- 文件名用本机时钟，时间被改过时日期就不准；文件名里没有时间到分钟，同一天多次归档靠 `-2` 区分。
- 归档内容仍然只有对话文本，不含工具参数、原始返回与产物文件。
- **真实子任务归档仍未通过**。本轮把排查结论写进了 AGENTS.md：主会话能调用 `subagent`（工具返回 `started subagent qa-sales`，profile 里生成子会话历史文件），但假模型服务收到的请求始终只有主会话那几次，没有一次由子会话发出；`subagent-spawn-in-process` 设计上应复用同一 cordis 上下文的 `llm-deepseek` 配置，实际为何没有请求尚未查实。`npm run test:subagent` 保持实验状态，不进发布门禁。
- 只在 Windows x64 实包验证；安装生命周期未复跑（`historical-upgrade` 仍 `not_run`）；安装器未签名；真实云端未覆盖。
