# 知行 0.12.0 · 原生内核与本机脱敏

2026-11-21 从 `4c245d5` 继续，内核仍锁定 `@deepseek-ai/dsh@0.2.2-rc.5`，没有将上游 master 的接口当作随包可用能力。当天查询 npm 的 `latest` 与 `next` 标签均为该版本。桌面、模型协议、权限和脱敏的实际实现分别核对；安装依赖与显示入口不等于已经验收。

## 脱敏实现和依据

当前引擎为 `0.12.0-local-v2`，是随包 JavaScript 规则识别器，不是云端脱敏服务，也没有内嵌 Presidio、scrubadub 或 Gitleaks 可执行引擎。

| 已实现 | 实际边界 |
| --- | --- |
| 全角/兼容字符、零宽与方向控制字符识别 | 使用规范化检测视图和原文 UTF-16 位置映射；替换与还原保留原文，不在原始资料上做不可逆规范化。不是任意编码、HTML 实体或 Base64 的解码器 |
| 15 类策略及字段上下文 | 姓名、机构、电话、邮箱、身份证、账户、护照、地址、生日、IP、MAC、路径、编号、凭证及自定义词。结构化字段支持常用英文/中文别名；无字段人名、任意地址及不同语言文本可能漏检 |
| 校验位识别 | 中国大陆身份证日期/校验位、Luhn 号码、IBAN MOD-97。不验证身份、账户存在性或所有国家证件规则 |
| 凭证规则 | 常见私钥、服务令牌前缀、JWT、授权头、带凭据的连接串及密码/令牌字段；补充全角和隐藏字符检测。长度至少 12 字符的当前模型 Key 另按精确值/规范化值拦截，覆盖请求、最终回复、部分草稿、执行预览和实时/最终共享任务板；真正 Key 不因任务板检查传入内核。短于 12 字符的自定义服务 Key 仍依赖通用规则，没有这一层独立值匹配 |
| 占位符与映射 | 只信任当前映射签发的占位符；伪造占位符不能遮蔽凭证。重叠规则采用更严格动作，不用自定义词降低拦截。凭证占位符不自动还原 |
| HTTP 边界 | Chat Completions / Messages 实际请求验证了 Unicode 脱敏、伪造占位符和凭证阻断；被拦截的请求没有到达本机上游收件端 |
| 解释和本机测试 | 显示类别、规则/上下文/校验/词典依据、处理动作和处数。测试输入仅在当前页面内存中处理，不写入工作区 |

通用凭证默认阻断，用户可将该类设为替换，但不能设为直接放行；这与当前模型 Key 的独立硬阻断应区分。其他类别可按用户明确策略替换、拦截或放行，排除词不豁免凭证。检测是规则覆盖，不是“识别全部隐私”的证明；本轮没有独立真实语料的召回率或误报率结论。

非脱敏模式的语义是原文发送，不执行类别的替换动作。若把通用凭证类别从默认“拦截”改为“替换”后再选择非脱敏模式，通用规则检查本身不会强制阻断原文；至少 12 字符的当前模型 Key 独立比较仍生效。需要凭证硬阻断时应保留该类默认拦截设置，不能把原文模式描述成任意策略下仍强制过滤所有凭证。

本轮参考并核对的官方资料：

- [Microsoft Presidio Analyzer](https://github.com/microsoft/presidio/blob/main/docs/analyzer/index.md)：组合识别器、正则、NER 与可扩展逻辑。知行目前没有接入其 NER 模型。
- [scrubadub](https://scrubadub.readthedocs.io/en/stable/)：检测器/后处理器的拆分与可扩展规则。知行未安装该 Python 包。
- [Gitleaks](https://github.com/gitleaks/gitleaks)：凭证规则、熵阈值和规则配置。知行仅补充了常见凭证格式与边界测试，没有声称运行其完整规则库或熵扫描。

- 常驻 Harness Host、跨轮持续 MCP/后台 job、MCP OAuth、按需工具加载与热重连；当前仍按轮启动并在加密历史中恢复。
- 增量加密事件帧和附件 Blob 存储；现有历史仍全量加密写回，`workspace.bin` 仍有 12 MiB 上限。
- 原生 `tool-fs`、ripgrep 搜索、局部文件编辑及完整 Agent Office 三工具/离线 Python 环境；现有 OfficeKit 预览/转换/重算和办公文件写出保留各自范围。

- 模型视觉、原图打码、图表理解、NER、图片/音频/PDF 原始字节或 Office 隐藏对象的全面脱敏。默认仍仅发送已提取并检查的文字，原始图像不因本轮更新自动放行。
- 带签名 thinking 含敏感值时仍停止重放；没有静默删除或改写供应商签名块。
- 加密溢出存储尚未完成，因此未启用会将完整结果写成明文的 `spill-local` / `spill-policy`。
- 真实云端全供应商、真人麦克风、物理 DPI、无障碍全量审计、Windows 签名与所有安装迁移分支仍需独立验收。
