# 知行 0.12.6 · 原生项目工具与会话导出

绑定工作目录的项目使用 DeepSeek Harness 固定版本 `0.2.2-rc.5` 的原生 `read`、`write`、`edit`、`apply_patch`、`glob`、`grep` 和 `read_image`。文本编辑需要观察当前文件版本，搜索使用随包 ripgrep；文件和搜索结果受项目范围、私密路径及脱敏规则约束。图片使用 Windows 本机生成的视觉副本，仅交给声明图片输入的模型；当前供应商、模型与思考档位保持用户选择。

文本写入、批量补丁、Office 转换和工作簿重算需要逐次批准时，桌面会显示真实的批准请求。一次补丁先审阅一批目标，上游预检通过后依次修改。中途停止时，先完成的修改继续保留，执行面板记为「未完成」。

桌面的「会话操作 → 导出聊天文件」支持 Markdown。选择「脱敏会话」或「非脱敏会话」后，主进程从该聊天的已提交加密日志读取并使用 Harness 原生格式化器。对外版按当前规则处理日志，本人版保留日志已有的值；两者都不还原旧占位符，凭据和当前禁止规则始终有效。审阅绑定聊天归属、文件格式、接收范围和当前隐私策略。导出不请求模型。

本轮覆盖主会话 Markdown，保留原有 TXT、DOCX 和 XLSX。ZIP、子会话和附件字节的完整归档另行验收。 [能力地图](harness-capability-map.md) · [Windows 验收](windows-acceptance-0.12.6.md)
