## 证据范围

文件观察的验证方式是真实打包应用 + preload 数据接口 + 外部进程写盘，未在真实桌面 UI 上逐个点击核对自动刷新；递归监视在超大项目目录下的句柄开销未压测。观察结果不会自动进入模型上下文。
