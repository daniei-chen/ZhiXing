# Codex / ChatGPT 桌面交互核对

日期：2026-11-19；证据：用户提供的 1255×912 截图，以及当前应用的屏幕和可访问性树。

## 已直接观察

- 框架：43px 顶栏，约 51px 图标轨道，约 239px 项目侧栏，白色主区。
- Codex 左上模式菜单：ChatGPT（创建、学习和探索）、Codex（构建、调试和发布）。
- ChatGPT 新聊天页：顶部“聊天 / 工作”切换，主区居中标题“我们从哪里开始？”，单行圆角输入框，Pro 模型、听写与语音入口。
- Codex 项目新聊天页：项目上下文、居中欢迎标记与标题，底部多行输入框，左侧加号与权限，右侧模型与强度、听写、语音/停止。
- 定时任务：单独侧栏；筛选、搜索、新建；无任务状态；主区六个示例任务。新建弹窗包含说明、重复（每天）、时间（中国时间 09:00）、高级、取消和创建。
- 插件：单独“自定义”侧栏、插件/技能、已安装列表；主区搜索、刷新、管理、添加、公开目录和分组条目。
- 项目操作、会话置顶/归档、活动、搜索、分享、摘要面板、标签页入口在可访问性树中确认存在。

## 安全检查范围

只检查页面、菜单与可逆模式切换。未发送真实消息、创建远程定时任务、安装插件、删除项目、修改账户或读取凭据。结束时恢复 Codex 模式。

## 仍需逐项核对

设置全部子页、权限确认框、分享最终流程、插件详情及安装流程、资料空间详情、站点、代码审查、实际录音与跨端同步。不能据此声称“所有功能已一比一完成”。

## 当前适配决策

以最新用户指示为准：单一工作台，删除 Codex／ChatGPT 模式切换；办公和政务通过工作空间及模板区分。官方账户、订阅和模型服务不属于可复制的服务；真实推理与工具执行使用独立的 DeepSeek Harness。

2026-11-19 追加验收：用户明确指定长文本输入区的参考截图和雪中三叶墨竹应用图标。0.1.1 的输入区尺寸、展开、滚动、工具栏，以及图标各处接入已核对；详细范围、证据、包内执行测试和剩余限制见 `../design-qa.md`。
