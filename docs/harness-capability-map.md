# 知行 · Harness 能力验收地图

本表区分实际运行的内核能力、界面接入和剩余工作。安装依赖、放置入口和读取目录均不等于端到端完成。用户要求的完整范围继续保留。

## 0.12.1 当前状态与证据分层

当前构建源码为 `25c6e69165cb019b834861e7bc33e9ddf46938f2`，固定 Harness `0.2.2-rc.5`。本轮处理边界和恢复合同，没有把所有上游可选插件接进桌面。具体安装器、实际包内回归及 Windows 旅程以 [0.12.1 验收页](windows-acceptance-0.12.1.md) 为准；下面的接线状态不代替该页的逐层结果。

## 0.12.0 已发布增量（历史基线）

已接入官方 Agent Teams、可选完整 PTC `run_code`、Windows PowerShell 写入沙箱，以及工具裁剪/重复提醒/协作式超时/时间上下文。修复主/子会话流式预览归属、非推理模型默认路由、上游重试、`present` 审批和规划模式检查顺序。脱敏新增 Unicode 检测视图、字段别名、校验位、占位符防绕过及可解释本机测试。

逐项源码、实包和界面证据见 [0.12.0 迭代记录](iteration-0.12.0.md) 与 [0.12.0 Windows 验收](windows-acceptance-0.12.0.md)。PTC 默认关闭且仅在完全访问与绑定项目时启用；Windows ACL 沙箱不代表全部读取与网络隔离。仍未接入常驻 Host、MCP OAuth、模型视觉、增量加密存储、独立搜索连接、完整原生 Office/文件工具和供应商账号登录，不能宣称内核能力已全部接入。
