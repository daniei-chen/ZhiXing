# 知行 · Harness 能力验收地图

本表区分实际运行的内核能力、界面接入和剩余工作。安装依赖、放置入口和读取目录均不等于端到端完成。用户要求的完整范围继续保留。

| 能力 | 当前接入 | 证据与边界 |
| --- | --- | --- |
| 模型与推理 | DeepSeek 原生适配器、Harness 多供应商适配器。预设和自定义 API 拉取模型，输入框单入口切模型与调强度 | 桌面端使用两条本机测试服务核对实际请求。原生服务四档另由内核测试核对。更换供应商时新开聊天，避免旧对话被发送到另一家服务 |
| 多轮会话 | 原生日志加密、恢复、压缩、目标、规划模式与审批 | 两种发送模式的历史分开。带正文和附件的规划交办在确认进入内核规划模式后发送受保护的完整提示 |
| 脱敏与还原 | 本机识别、分类策略、自定义词、排除词、请求网关、工具输出保护和任务映射 | 手动交办自动处理并发送；凭证另行阻断；未解析附件不能标为已脱敏 |
| 浏览器面板 | 原生 WebContentsView、多标签、项目快捷入口、仅本次运行的站点卡、网页文字加入交办、可见区域截图另存 PNG | 源码回归核对导航、隔离与 PNG。Windows 界面核对本机短地址、站点卡、文字加入交办与截图另存。Agent 有文字快照、点击、输入工具，网页截图作为模型视觉输入仍待接入 |
| 文件面板 | 项目文件、文字提取、Office/PDF 本机版面分页、转换和工作簿重算 | 版面和转换使用原生 OfficeKit。可将提取文字加入交办。转换和重算另存新文件，保留源文件 |
| 终端面板 | Harness 真实 PTY、PowerShell/cmd、屏幕恢复、调整尺寸、多标签 | 用户终端独立于 Agent；模型使用单独受审批的 `office_execute` |
| 执行与统计 | 按交办和事件类型筛选，查看详情、耗时和协作状态。运行统计随内核快照更新 | 每次手动交办保存最近 400 条事件摘要。历史记录使用知行的加密存储 |
| 原生技能 | 知行办公与政务流程、Harness Office 技能、当前项目自定义技能 | 内核目录检查无模型调用；本机 Python/Office 工具运行条件仍影响实际操作 |
| 子 Agent | spawn、fork、状态、中断、运行中发送补充及查看近期子会话 | 由 Harness 子任务服务执行。源码回归验证父会话先空闲时仍能收到子任务的最终回复。运行中每个子任务最多保留近期 16 条摘要，归档后完整子会话日志仍待接入 |
| 工作流与作业 | 原生 workflow/PTC、job_list/output/kill、生命周期事件，执行面板可读输出并请求停止 | 源码合成交办核对作业输出。作业随本次内核进程结束，跨启动持久运行和完整日志待验 |
| MCP | stdio、Streamable HTTP、工具、资源列表和读取、加密凭据 | 非文本返回暂不接入模型附件隐私链；不是任意插件市场的替代品 |
| 自动化 | 主进程持久调度、日/周/月/年/工作日/单次、延迟、间隔、Cron、RRULE、执行历史、取消、自然语言草稿 | 高级规则使用 Harness 时间引擎。支持每次新建聊天、固定一条任务聊天及既有聊天结果投递。既有聊天只用已审阅的上下文，任务使用独立内核会话。应用退出后不执行 |
| 成果 | 原生 present、工作区文件卡、DOCX/XLSX/TXT 导出，可从文件面板按支持格式转换并另存 | 版面基于本机字体和 Office 打印布局。工作表重算更新公式缓存 |
| 设置 | 主题、项目工作区、模型、MCP、权限、隐私、语音、办公偏好、内核限制和版本检查 | 版本与 npm 官方标签核对。用户填写的办公偏好使用同一脱敏链，定时任务沿用已审阅内容 |
| 品牌图标 | 用户墨竹原图、网页标识、窗口、EXE、安装/卸载包、带品牌的开发入口 | `scripts/verify-brand.mjs` 对比 PE 图标资源；任务栏还需打开正确的新入口核对 |
| 插件与市场 | 自定义页包含官方目录、可添加的目录索引与 MCP。原生管理器支持定版安装、启停、兼容更新、移除，以及发现构建脚本时逐次审阅 | Windows 界面核对目录添加、搜索、版本及来源。源码用合成 npm 包验证构建脚本拒绝、批准、安装和后续加载；Git 来源有路由，实际 Git 安装与实验插件配置仍待验。已信任的插件只用于完全访问且关联工作区的主动交办 |
| PDF、PPTX 输入 | 已接入文字提取 | 中英文文字 PDF、文字注释/字段、PPTX 原始页序/隐藏页/演讲者备注；原始文件不上传。`tests/document-text.test.mjs` 包含链接/脚本不访问网络、中文 ToUnicode、读取边界和包内运行验收 |
| Word / Excel 复杂文字 | 已扩展 | Word 正文/页眉页脚/脚注尾注/批注/修订，Excel 隐藏区域/合并格/批注/公式缓存，均保留读取范围。公式未重新计算；原生文件未修改 |
| 图片与扫描件 | Windows 本机 OCR 识别扫描图及 Office/PDF 版面并标记覆盖范围，可加入交办 | Windows 界面见中文扫描图识别及加入交办。扫描页源图和图表的模型视觉输入仍待接入 |
| 语音 | Windows 本机听写、预览、取消、手动插入输入框 | 本机中文识别器已用合成音频跑通。真人麦克风、不同口音和持续语音对话还需验收 |
| 桌面交互与视觉 | 墨竹品牌与中性色。模型与思考强度单入口，滑杆浮层通向模型选择，最近聊天可折叠，有会话运行状态 | 当前验收范围和截图见 `design-qa.md` |
| DeepSeek 聊天导入 | 侧栏「新聊天」旁支持导入官网第 3 版 ZIP，保留当前分支、随包图片、附件记录、导出的推理和浏览记录 | 复用官方解析器和本机附件存储，PNG 会正规化为 WebP。最多 32 MB、100 段聊天，每段最多 80 条正文。只有名称的附件显示文件记录。旧日志完整迁移仍待接入 |

## 官方能力核对范围

0.2.2-rc.5 随包提供的 `docs/capability-seams.zh.md`、`docs/tool-catalog.zh.md` 和 `dsh-base/cordis.patch.yml` 是后续核对基线。当前运行的是嵌入式 SDK 配置，已启用的插件以 `electron/runtime.mjs` 和实际内核工具清单为准。

| 待补能力 | 官方入口与知行对应页面 |
| --- | --- |
| 扩展插件配置 | 自定义目录和构建脚本审批已接入。Git 来源安装的实测、实验插件的独立配置页面仍待完成 |
| 原生调度 Host 的补足 | 已复用 `dsh-util-time` 和 `dsh-schedule` 的时间引擎与决策函数。知行仍由主进程加密调度，使用审阅后的指令投递，尚未采用官方的 Host 调度存储、向原生已有会话直接追加消息或同目标的多任务批投递 |
| 原生供应商登录 | `dsh-llm-pi-ai` 的 OAuth / 认证服务 → 供应商连接。当前使用 API Key |
| 会话完整迁移与排查 | 现已导入可见正文、随包图片和导出中的部分活动。全分支历史、完整工具事件与独立会话日志浏览仍待接入 |
| Git 工作树 | 原生 Harness 在独立 Git 仓库的源码测试中通过创建、恢复和路径校验。项目菜单已接入创建与恢复。Windows 界面已发起创建，仍待核对最终状态及界面恢复 |
| 可选或实验集成 | 官方文档标记的计算机操作、第三方浏览器驱动、Forge、远程翻译有各自的运行条件，仍待逐项核对 |

收尾门槛：源代码测试、真实桌面交互、从源码目录外启动打包内核、EXE/安装包图标资源验证及截图检查分别记录。未覆盖项保留为未完成，不以“全部通过”掩盖。
