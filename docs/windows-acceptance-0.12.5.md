## Office、命令与隐私

- 源码和包内原生回环核对了实际 PDF 文件头、回执大小和同名另存。工作簿公式保留，缓存由 99 更新为 7。审批拒绝、项目外路径和规划模式下的写操作均无产物。会话重开后加密历史保存原生交付记录。
- DeepSeek Messages 本机回环比较原页和实际模型收件，遮罩副本复跑 OCR 后无法读出合成电话。重开后复用相同副本，策略变化后阻断出站。文字模型实际工具目录不开放 `office_render`，模拟模型发起同名调用时收到错误结果。
- Windows 目录包中用 `/计划` 进入规划，用对话按钮退出，原交办草稿保留，模型请求计数为零。用该草稿提交后，Chat Completions 合成服务收到三次请求，可核对一次渲染与一次转换。供应商保持配置值，模型 `qa-office-vision`，思考档位 `high`。复 OCR 核对实收图像保留标题文字并遮住电话。PDF 新文件 13,128 bytes，源 DOCX 字节不变。
- 完整退出并重启同一隔离档案后，通过聊天的原生成果卡片打开 PDF。追问产生第四次模型请求，重放 22,892 bytes 的 `image/png`，三次实收 SHA-256 均为 `d49aa0e00580757795b06fbbe5a21efe91aabba84c4710778d980f074ca5879e`。两次退出的进程退出码均为 0。
- Windows 专项使用「帮我批准」写入新的文件。源码合成回环覆盖逐次批准与拒绝，但 0.12.5 的桌面审批分发尚未接入新增的转换和重算工具。需要逐次确认时，本版会拒绝；已发现的桌面分发缺口留给下一版修复及实测。
