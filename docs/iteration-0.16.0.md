# 知行 0.16.0 · 移除单个模型，工具结果也走脱敏

## 两个问题

1. **拉取到的模型只能切换，不能删**：供应商详情里 47 个模型全都在，输入框浮层也跟着列全部。用户上一轮明确要求「删除模型」，之前只能整个供应商移除。
2. **工具结果路径的脱敏没有证据**：0.15.x 只证明了模型请求正文被掩码（多轮问答还原），文件工具读出来的内容进入下一轮请求时是否同样掩码，一直没测。

## 怎么改

**移除单个模型**（`electron/providers.mjs`、`electron/main.cjs`、`electron/preload.cjs`、`src/ProviderSettings.jsx`）

- 供应商记录新增 `hiddenModels`；`publicProviders` 与 `providerModels` 都按它过滤，所以模型目录、输入框模型列表、路由三处一致。
- 供应商详情的每个模型行右侧加移除按钮；移除后列表少一行，底部出现「已隐藏 N 个模型 · 恢复全部」。
- 如果移除的正是当前模型，当前模型自动落到第一个剩余模型，并提示换了哪个。
- 新 IPC `providers:hidden-model`（`setModelHidden` 是纯函数，4 个单测钉住：隐藏、恢复、重复隐藏、未知供应商/模型）。

**工具结果脱敏验收**（`scripts/test-real-cloud-tool-redaction.mjs`，`npm run test:tool-redaction`）

- 工作区放 `contact.md`，内容含假手机号 `13800138000` 与假邮箱 `qa-tool-redaction@example.com`；
- 进项目会话，让模型用文件工具读出来并原样贴出；
- 断言：界面还原成原文；再问「你看到的是 11 位数字原文还是别的记号」，模型自述是占位符且**没有**贴出原始号码；应用日志不含号码与 Key。

## 边界

- **符号不乐观**：一条有意的拦截在测试中暴露出来——如果让模型**原样复述**它看到的占位符，回答会带出无法归属本次任务的记号，界面整段显示「输出包含无法归属本任务的占位符，已停止还原」。这是防跨任务误还原的保护，不是缺陷；但它会牺牲整段回答。本版没有改这个行为，只把问法改成「不要复制记号」，因此**「模型复述占位符时如何优雅降级」仍是未覆盖的产品问题**。
- 隐藏模型只影响展示与路由，不删除供应商记录；重新「拉取模型」不会把它带回来（隐藏清单优先）。恢复入口只有供应商页的「恢复全部」。
- 工具结果脱敏只验了手机号与邮箱两类；Key/身份证/银行卡等其他类别、以及工具返回的二进制/图片仍未覆盖。
- 工作区仍由脚本注入，不是从「新建项目」对话框创建。
- 安装生命周期本轮未重跑；真实子任务归档仍未通过；安装器未签名；`visualAcceptance`、`crossWindowsUserDecryption` 仍 `outside_scope`。
