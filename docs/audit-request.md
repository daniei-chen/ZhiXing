# 知行 0.11.0 源码预览审计

审计以 `v0.11.0-preview.1` 的源码和锁文件为准。请核对 Windows Electron 界面、主进程 IPC、DeepSeek Harness、模型请求网关和本地存储之间的实际调用链。

## 请重点核对

1. **Git 工作树**：项目菜单能否创建独立工作树并恢复缺失检出。检查项目隔离、路径与分支校验、Windows 沙箱权限、失败反馈及中断后恢复。
2. **图片视觉输入**：区分 OCR 文本、历史图片和发送给视觉模型的图片。检查供应商能力判断、附件大小和格式、用户确认、隐私网关及历史重放。默认脱敏模式需要继续保护原始图片。
3. **供应商 OAuth**：明确 Harness 支持的服务和登录方式。检查授权、回调或设备码、令牌加密、刷新和登出，以及更换账户后的历史隔离。
4. **完整会话迁移**：核对支持的导出格式、分支、附件、推理和工具事件。检查去重、重复导入、失败回滚及大小限制。
5. **Windows 发布**：核对新工作区、输入框、浏览器与文件面板、定时任务、设置和历史迁移的操作路径。检查从干净目录启动打包后的内核。

## 请交付给开发代理

按严重程度列出发现。每条给出源码路径、行号、复现条件、预期结果和影响。随后按依赖顺序给出实施计划，为每步列出要改的模块、自动化验证和 Windows 界面验收标准。最后列明需要测试账户或现场操作的步骤，以及阻止发布正式安装包的事项。
