# 知行 0.12.8 · 会话工作目录

绑定项目后接入 DeepSeek Harness `0.2.2-rc.5` 官方 `dsh-tool-working-directory`。模型可以查看当前工作目录，或切换到项目内已存在的子目录；`read`、`write`、`edit`、`apply_patch`、`glob`、`grep` 的相对路径随该目录解析，绝对路径与项目边界校验保持不变。

切换目标先按当前目录还原，再经 `workspaceTarget` 确认是项目内的真实目录：项目外、符号链接与含已配置凭证的路径在切换前拒绝。目录变更写入 `working-directory/change` 事件并随会话保存，重开继续生效；计划模式可以查看当前目录，但不能移动。执行轨迹显示「会话工作目录」，能力清单新增一项，随内核开关一起启停。

本轮验证为源码与本机合成回环：在合成项目里切到子目录后，读取命中子目录同名文件、写入落在子目录并触发一次审批、搜索只在子目录命中，`../..` 被拒绝且不改变后续操作，重开会话后目录与结果保持。Windows 目录包、桌面专项与安装生命周期证据见 [Windows 验收](windows-acceptance-0.12.8.md)。 [能力地图](harness-capability-map.md)
